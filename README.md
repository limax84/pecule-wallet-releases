# Pécule Wallet — distribution

APK Android signés de Pécule Wallet. Le dépôt source est privé.

Chaque release installable fournit un APK, son SHA-256, un manifeste et sa signature détachée. La recherche dans l’application est exclusivement manuelle.

La version 0.10.0 est en préparation et n’est pas encore publiée.
