# Pécule Wallet — distribution

[Préversion v0.10.0 (versionCode 11)](https://github.com/limax84/pecule-wallet-releases/releases/tag/v0.10.0)

Android 11 minimum, ARM64. Installer par-dessus la version précédente sans désinstaller pour préserver les données. Le certificat de signature existant est conservé.

Chaque release fournit l’APK, SHA256SUMS, release-manifest.json et sa signature détachée release-manifest.sig. Lire les notes et les limites de validation avant utilisation. Aucun déni plausible cryptographique n’est revendiqué.

Ce dépôt contient uniquement les informations de distribution et les artefacts publics. Le dépôt source reste privé. Aucun secret ni donnée de wallet n’y est distribué.
